# QuizApp


## Überblick

QuizApp ist ein einfaches und unterhaltsames Quizspiel, bei dem Spieler sechs Fragen mit jeweils vier Antwortmöglichkeiten beantworten können. Es kann immer nur eine Antwort richtig sein. Die App bietet ein interaktives Spielerlebnis mit visuellen Rückmeldungen und Soundeffekten, die je nach Richtigkeit der gegebenen Antworten abgespielt werden. Nach Beantwortung aller Fragen wird das Ergebnis angezeigt und es besteht die Möglichkeit, das Spiel erneut zu spielen.

## Funktionen

6 Fragen: Das Quiz umfasst sechs Fragen, die aus verschiedenen Themenbereichen stammen können.
4 Antwortmöglichkeiten pro Frage: Jede Frage bietet vier verschiedene Antwortmöglichkeiten, von denen nur eine richtig ist.

### Visuelle Rückmeldung:
Bei einer richtigen Antwort wird das gewählte Feld grün hinterlegt.
Bei einer falschen Antwort wird das gewählte Feld rot hinterlegt und die richtige Antwort grün angezeigt.

### Soundeffekte:
Richtig beantwortete Fragen lösen einen Erfolgston aus.
Falsch beantwortete Fragen lösen einen Fehlerton aus.
Ergebnisanzeige: Am Ende des Quiz wird die Anzahl der richtig beantworteten Fragen angezeigt.
Neustart-Option: Nach Abschluss des Quiz gibt es die Möglichkeit, das Spiel neu zu starten und die Fragen erneut zu beantworten.
